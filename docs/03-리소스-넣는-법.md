# 리소스를 어디에 넣는가

이미지·사운드를 넣을 위치와 규칙. **폴더는 `gen` 이 자동으로 만들어 줍니다** — 직접 만들 필요 없습니다.

---

## 폴더 구조

게임을 생성하면 이렇게 만들어집니다.

```
Assets/Games/<게임이름>/
├─ Core/          ← 자동 생성. 게임 로직. 손대지 마세요
├─ Unity/         ← 자동 생성. 화면 코드. 손대지 마세요
├─ Editor/        ← 자동 생성. 메뉴. 손대지 마세요
│
├─ Resources/     ★ 여기에 넣습니다. 재생성해도 안 지워집니다
│   ├─ Icons/         버튼 아이콘
│   ├─ Sprites/       월드 스프라이트 (판·유닛·적)
│   ├─ Backgrounds/   배경
│   └─ Audio/         사운드
│
├─ README.md              ← 자동 생성. 이 게임 요약
└─ 리소스-넣는-법.md       ← 자동 생성. 게임별 맞춤 안내
```

`gen` 을 다시 돌려도 **`Resources/` 안의 내용은 건드리지 않습니다.** 넣어둔 이미지는 안전합니다.

---

## 연결하는 법 — 파일명만 적습니다

**폴더 경로도, 확장자도 적지 않습니다.**

```
1. gold.png 를 Resources/Icons/ 에 넣는다
2. 기획서에  "icon": "gold"  라고 적는다
3. gameforge gen 으로 재생성한다
```

코드가 `Icons/` → `Sprites/` → `Backgrounds/` → 루트 순으로 알아서 찾습니다.
같은 이름이 여러 폴더에 있으면 앞쪽이 이깁니다.

**`icon` 을 비워두면 색 플레이스홀더가 자동 생성됩니다.** 그래서 아트가 하나도 없어도 게임은 굴러갑니다.
게임을 먼저 완성하고 나중에 이미지를 부으면 됩니다.

---

## 폴더별 규칙

### Icons/ — 버튼 아이콘

하단 버튼 목록에 뜨는 작은 그림.

| 항목 | 값 |
|---|---|
| 권장 크기 | 128 x 128 px (정사각형) |
| 형식 | PNG, 투명 배경 |
| Texture Type | **Sprite (2D and UI)** |

장르별로 필요한 것:

| 장르 | 아이콘이 붙는 곳 |
|---|---|
| 매치3 | 자원 |
| 머지 | 자원 |
| 방치형 | 자원, 시설, 업그레이드 |
| 서바이버 | 자원, 무기 |
| 타워디펜스 | 자원, 타워, 적 |
| 오토배틀러 | 자원, 유닛 |

### Sprites/ — 월드 스프라이트

화면 가운데에 실제로 그려지는 것. 판의 칸, 경로 위 유닛, 배치 슬롯.

| 항목 | 값 |
|---|---|
| 권장 크기 | 256 x 256 px 이하 (정사각형) |
| 형식 | PNG, 투명 배경 |
| Texture Type | **Sprite (2D and UI)** |
| Pixels Per Unit | **기획서 `art.pixelsPerUnit` 과 같게** (기본 100) |
| Pivot | Center |

크기가 서로 달라도 코드가 칸에 맞춰 자동으로 조정합니다.
다만 Pixels Per Unit 이 어긋나면 의도보다 크거나 작게 보입니다.

**픽셀아트라면** Filter Mode = `Point (no filter)`, Compression = `None`. 안 그러면 뿌옇게 나옵니다.

### Backgrounds/ — 배경

| 항목 | 값 |
|---|---|
| 권장 크기 | 1080 x 1920 px (세로 화면) |
| 형식 | PNG 또는 JPG |

> 현재 배경은 카메라 단색으로 칠합니다. 배경 이미지를 실제로 쓰려면 기획서에 항목을 추가해야 하니 요청해 주세요.
> 지금은 폴더만 준비된 상태입니다.

### Audio/ — 사운드

| 접두사 | 용도 | 권장 형식 |
|---|---|---|
| `bgm_` | 배경음악 | OGG, Load Type = Streaming |
| `sfx_` | 효과음 | WAV, Decompress On Load |

> **사운드 재생은 아직 생성기에 없습니다.** 폴더만 미리 만들어 둔 상태입니다.

---

## 빠진 이미지 확인

```
메뉴 > GameForge > <게임 이름> > 리소스 점검
```

기획서가 참조하는데 실제로 없는 이미지를 콘솔에 전부 찍어 줍니다.
빠져 있어도 플레이스홀더로 계속 굴러가므로 진행이 막히지는 않습니다.

---

## 주의

- **`Resources/` 안의 파일은 전부 빌드에 포함됩니다.** 안 쓰는 이미지를 쌓아두지 마세요.
- **`Core/` `Unity/` `Editor/` 에는 아무것도 넣지 마세요.** 재생성 때 폴더째 덮어써집니다.
- 파일명은 영문·숫자·밑줄을 권장합니다. 한글 파일명도 동작하지만 기획서와 대조하기 번거롭습니다.
